# Gezeitenschlurfer – Statistiken

Ertrunkene, die die Grotte nie verlassen haben: Gestalten aus Tang,
Treibholz und dem, was das Meer nicht behalten wollte.

| | |
|---|---|
| Typ | Untoter, Mittelgroß |
| RK | 13 (verhärteter Tang) |
| TP | 45 |
| Bewegung | 7,5 m, Schwimmen 12 m |
| STR 16 (+3) | GES 10 (+0) |
| KON 16 (+3) | INT 5 (−3) |
| WEI 10 (+0) | CHA 4 (−3) |
| Resistenzen | Kälte; Wucht/Stich aus nicht-magischen Angriffen |
| Verwundbarkeit | Feuer |
| Immunitäten | Gift, Erschöpfung |
| Sinne | Dunkelsicht 18 m, Wassersinn (spürt Bewegung im selben Gewässer, 18 m) |
| HG | 2 (450 XP) |

**Tangtarnung:** Regungslos im Wasser ist ein Schlurfer von einem
Tanghaufen nicht zu unterscheiden (Wahrnehmung DC 14).
