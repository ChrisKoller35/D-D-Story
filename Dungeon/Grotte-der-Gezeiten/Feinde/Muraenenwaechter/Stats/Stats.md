# Muränenwächter – Statistiken

Riesige Muränen mit perlmuttartig gepanzerten Schädeln – vor
Jahrhunderten als Grabwächter gebunden, inzwischen halb wild.

| | |
|---|---|
| Typ | Monstrosität, Groß |
| RK | 15 (Perlmuttpanzer) |
| TP | 60 |
| Bewegung | 3 m (an Land schlängelnd), Schwimmen 15 m |
| STR 17 (+3) | GES 16 (+3) |
| KON 15 (+2) | INT 4 (−3) |
| WEI 12 (+1) | CHA 5 (−3) |
| Fertigkeiten | Heimlichkeit +5 (im Wasser +7) |
| Resistenzen | Kälte |
| Sinne | Blindsicht 18 m (nur im Wasser), Dunkelsicht 18 m |
| HG | 3 (700 XP) |

**Lauerjäger:** Muränenwächter greifen bevorzugt aus Spalten und
trübem Wasser an (Vorteil auf den ersten Angriff aus Verborgenheit).

**Wasser-Heimvorteil:** Gegen Ziele, die schwimmen oder im hüfthohen
Wasser stehen, haben Muränenwächter Vorteil auf Angriffe.
