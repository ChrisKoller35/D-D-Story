# Vorgazhul – Statistiken

Balanciert für **4 Helden, Level 7**.

## Phase 1: Der Spiegelherr (Spiegelschild aktiv)

*In dieser Phase ist Vorgazhul „unendlich stark" – er hat keine
regulären Trefferpunkte und kann NICHT besiegt werden, nur geflohen
(Akt 2) oder per Siegel-Ritual gebrochen werden (Finale).*

| | |
|---|---|
| Typ | Unhold (Dämonenfürst), Groß |
| RK | 19 (zersprungenes Glas) |
| **TP** | **∞ (unverwundbar, solange der Spiegelschild steht)** |
| Bewegung | 9 m schwebend |
| STR 24 (+7) | GES 16 (+3) |
| KON 22 (+6) | INT 20 (+5) |
| WEI 18 (+4) | CHA 24 (+7) |
| Rettungswürfe | alle mit +6 zusätzlich |
| Immunitäten | Gift, Bezauberung, Furcht, Erschöpfung; nicht-magische Angriffe (reflektiert sowieso) |
| Sinne | Wahre Sicht 36 m |
| Sprachen | alle (spricht mit der Stimme des Zuhörers) |

**Leylinien-Anker:** Vorgazhul ist an den Ritualort (Keller der
Festhalle) gebunden; max. 150 m Entfernung. Innerhalb Sommerhall gilt
seine Spiegelkuppel. Wird der Ritualkreis zerstört (→ Finale,
Szenario D), verliert er Wahre Sicht und die Rettungswurf-Boni.

**Spiegelschild (Kernmechanik):** 10 Aufladungen, Details →
`../Faehigkeiten/Faehigkeiten.md`. Bei 10 Aufladungen: **Weltenspiegel**
→ `../Ultimative-Faehigkeiten/Ultimative-Faehigkeiten.md`.

## Phase 2: Der Gebrochene Spiegel (nach dem Siegel-Ritual)

*Erst jetzt hat Vorgazhul echte Werte. Deadly Encounter für 4× Lvl 7 –
die Gruppe soll gewinnen, aber es soll sich wie ein Finale anfühlen.*

| | |
|---|---|
| RK | 17 (Risse im Glas) |
| TP | 190 |
| Bewegung | 9 m schwebend |
| Attribute | wie Phase 1 |
| Rettungswürfe | STR +11, KON +10, WEI +8, CHA +11 |
| Resistenzen | Kälte, Feuer, Blitz; Wucht/Hieb/Stich aus nicht-magischen Angriffen |
| Immunitäten | Gift, Bezauberung, Furcht |
| Verwundbarkeit | **gegen die Klinge der Stille: +1W8 Schaden** |
| Sinne | Dunkelsicht 36 m (Wahre Sicht ist mit dem Schild zerbrochen) |
| HG | 13 (10.000 XP) |

**Legendäre Resistenz (2/Tag):** Misslungenen Rettungswurf in Erfolg
umwandeln – dabei fällt hörbar eine Glasscherbe von ihm ab (zeigt den
Spielern die begrenzte Ressource).

**Splitterpanzer:** Wer Vorgazhul mit Nahkampfangriff trifft, nimmt
4 (1W8) Stichschaden durch abplatzende Glassplitter (NICHT bei der
Klinge der Stille).

Angriffe und legendäre Aktionen → `../Faehigkeiten/Faehigkeiten.md`,
Ultimative der Phase 2 → `../Ultimative-Faehigkeiten/Ultimative-Faehigkeiten.md`.
