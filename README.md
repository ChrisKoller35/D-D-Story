# D&D Story-Projekt

Unser Dungeons-&-Dragons-Kampagnen- und Story-Projekt.

## Ordnerstruktur

- **Kampagne/** – Übergreifende Story, Hauptplot, Weltenbau
- **Charaktere/** – Spielercharaktere (SCs) und wichtige NPCs
- **Orte/** – Städte, Dungeons, Regionen, Kartenbeschreibungen
- **Sessions/** – Protokolle und Vorbereitungen einzelner Spielabende
- **Ideen/** – Lose Ideen, Plot-Hooks, noch unsortiertes Material

## Arbeiten mit Claude

Dieses Projekt wird über ein privates GitHub-Repository zwischen mehreren
PCs synchronisiert. Nach jeder Arbeitssitzung werden die Änderungen
hochgeladen (committet und gepusht), damit sie auf dem anderen PC
verfügbar sind.

Auf einem neuen PC weiterarbeiten: Claude Code öffnen und sagen
„Hole mein D&D-Projekt von GitHub" – oder manuell:

```
git clone <Repository-URL>
```
